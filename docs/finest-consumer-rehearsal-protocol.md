# Actual consumer output-memory rehearsal: prospective protocol

Scope: implement and exercise the actual minimal finest-source output consumer,
with resource-only synthetic fields in place of the long Green evaluation.
Same input/import path, retained complex128 buffers, pressure-load function,
checkpoint writer, hashing, array verification and payload packaging are intended
for the future actual producer. No full field run, BEM source solve, remeshing,
new physics/formulation or optimization campaign. No physical promotion possible:
resource_only=true, synthetic_fields=true, source/reference/full-run flags false.

Require SHA-pinned accepted native cost probe and its complete physical/code/input
graph, actual dependency/native-library identity and refreshed host availability.
Archive actual consumer code, controls, physical input and exact input bundles
before native work. Use selected array loading only AFTER verifying the complete
historical payload SHA and archived producer graph. Retain common target arrays
and source-summary matrices, not unrelated old fields or an extra95MB quadrature
graph. Both discarded fields and their producers remain in pinned input archives.

Declare60s TOTAL wall cap including preparation/import/native calibration/output
stages,2GiB peak working-set AND peak committed-memory caps and2GiB additional
disk cap. Host availability must exceed1.25×previous estimated peak memory and
2×additional-disk ceiling; record observations and monitor process peaks before/
after native calls and each output stage. Actual source3456 centroid calibration
is the ONLY native field workload: repeat all six potentials/all36 loads at
unchanged1e-10 scaled tolerance, physical surface/radii/CG/inertia/Green checks.

Verify complete124416/221184/345600 owned target grids belowz0, same normals and
weights from the pinned common result. Allocate AND touch all691200×6 complex
fields (66,355,200 bytes) and keep every order resident. Native retained fields

imaginary data in100-row blocks, to exercise both memory pages and pessimistic
packaging size. Synthetic traces are never reference potentials. The shared
consumer computes all36 pressure-load entries at full grid size for each order.

Actual native evaluation supports caller-owned complex buffers via the same
evaluate_trace helper, preventing a different array-lifetime path in the future
real producer. Rehearsal and actual providers fill the same retained buffers;
all loading/load/checkpoint/verification/packaging stages are otherwise shared.
Current controls authorize ONLY the rehearsal provider. A separately declared
real-run goal is still required.

Write complete NPZ checkpoints after each order and final load arrays. Freeze
the final NPZ bytes thereafter; metadata-only stage updates preserve that SHA.
Verify raw SHA using streaming reads and compare every restored array, one at a
time. Package actual NPZ, payload-manifest snapshot and producer/physical graph,
with SHA-bound external inputs. Verify ZIP CRC, embedded metadata and streamed
NPZ SHA. The payload snapshot intentionally precedes final packaging metrics;
the external final manifest records its exact SHA. No hidden whole-payload or
whole-restored-graph copies are part of this consumer. Preserve the exact pipeline
for real outputs. Count all actual source/input/checkpoint/payload file bytes
plus64KiB final metadata allowance against disk ceiling.

Acceptance requires every stage in order: inputs,native,checkpoint12,
checkpoint16,checkpoint20,final_checkpoint,array_verification,package_verification;
all identities/calibration/ownership/finite-field checks; complete retained
buffers; successful raw and packaged roundtrips; time/memory/disk caps. Missing/
failed stages cannot pass. No resource ceiling or numerical tolerance changes
after observation. Rehearsal_passed is only a resource result; overall passed
and all physical/full-run flags remain false even if synthetic loads happen to
agree. Model-versus-measured memory remains explicit.

Deliver actual immutable producer/input/stage-memory evidence, raw resource
arrays and payload package, focused identity/buffer/roundtrip tests, independent
prelaunch/postrun review, tracker and fresh handoff. Commit/push checkpoint and
stop after the rehearsal decision. Separately reviewed full four-source physical
continuation and finite A/B/excitation/phase gates remain required. Offline costs
